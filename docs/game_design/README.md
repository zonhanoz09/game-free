# Game design

Tài liệu game design được tổ chức theo một nguồn sự thật và một thứ tự phát triển
tuần tự:

- [`system_game.md`](system_game.md): luật gameplay, công thức, roster và effect
  contract.
- [`gameplay.md`](gameplay.md): mô tả gameplay hiện hành cho team, UI và QA.
- [`roadmap.md`](roadmap.md): phase phát triển, dependency và cổng nghiệm thu.
- [`ENGINEERING_EXECUTION_PLAN.md`](ENGINEERING_EXECUTION_PLAN.md): kiến trúc
  kỹ thuật và quy tắc triển khai theo phase.

Không đưa roadmap vào `gameplay.md`, không đưa balance hardcode vào client, và
không bắt đầu phase sau khi phase trước chưa đạt cổng nghiệm thu.
